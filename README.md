# BOSS终极自动投递系统 使用说明

## 简介

这是一个用于BOSS直聘（zhipin.com）的油猴脚本，可自动投递简历并发送打招呼消息。

## 安装步骤

### 1. 安装油猴扩展

首先需要在浏览器中安装 Tampermonkey 扩展：

- **Chrome**: [Chrome 网上应用店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- **Edge**: [Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- **Firefox**: [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### 2. 安装脚本

1. 点击浏览器工具栏的 Tampermonkey 图标
2. 选择「添加新脚本」
3. 将脚本代码粘贴到编辑器中
4. 按 `Ctrl+S` 保存

## 功能说明

### 主要功能

| 功能 | 说明 |
|------|------|
| 自动投递 | 自动匹配关键词投递简历 |
| 智能过滤 | 排除包含指定关键词的职位 |
| 自动打招呼 | 投递时自动发送预设消息 |
| 防封机制 | 智能延迟，每50次投递休息30秒 |

### 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 关键词 | `前端,Vue,React` | 职位标题包含这些关键词才会投递 |
| 排除词 | `外包,驻场` | 包含这些关键词的职位会被跳过 |
| 打招呼语 | `您好，我对这个岗位很感兴趣，期待沟通！` | 自动发送的消息 |
| 最大投递数 | `300` | 单次运行最多投递数量 |

## 使用方法

### 1. 打开BOSS直聘

访问 [https://www.zhipin.com](https://www.zhipin.com) 并登录账号。

### 2. 进入职位列表页

可以通过以下方式进入职位列表：
- 搜索职位关键词
- 点击推荐职位
- 进入某个公司的职位列表

### 3. 启动脚本

页面右上角会出现控制面板：

```
┌─────────────┐
│ [开始] [设置] │
└─────────────┘
```

- 点击「**开始**」启动自动投递
- 再次点击可停止运行
- 点击「**设置**」修改关键词、排除词和打招呼语

### 4. 查看日志

按 `F12` 打开开发者工具，切换到 Console 标签页，可以看到投递日志：

```
[终极版] 投递(1) 前端开发工程师
[终极版] 投递(2) Vue开发工程师
[终极版] 休息30秒
[终极版] 完成
```

## 延迟策略

脚本采用智能延迟策略，降低被封风险：

| 投递次数 | 延迟时间 |
|----------|----------|
| 0-50 | 3-4 秒 |
| 51-150 | 4-6 秒 |
| 151+ | 5-8 秒 |

每投递 50 个职位，会自动休息 30 秒。

## 注意事项

1. **账号安全**: 请勿过于频繁使用，建议每天投递不超过 300 个
2. **关键词设置**: 根据自己的求职意向设置合适的关键词
3. **排除词设置**: 建议排除「外包」「驻场」「劳务派遣」等
4. **浏览器标签**: 运行时请保持标签页在前台，否则可能无法正常滚动页面

## 常见问题

### Q: 脚本没有运行？

检查以下几点：
1. 确认 Tampermonkey 已启用
2. 确认脚本已启用
3. 刷新页面重试
4. 检查是否在 zhipin.com 域名下

### Q: 投递后没有发送打招呼？

部分职位可能不支持自动发送消息，这是正常现象。

### Q: 如何修改最大投递数？

在脚本代码第 18 行修改 `max` 的值：

```javascript
max: 300  // 改为你需要的数量
```
